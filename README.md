# Bundesliga Wrapped

Bundesliga Wrapped is a first-draft React Native / Expo prototype inspired by Spotify Wrapped. It generates personalised, shareable season recap cards for Bundesliga fans using mock club, player, match, video, and user behaviour data.

## Features

The prototype generates six Wrapped cards:

1. Fan Aura + Signature Moments
2. Jersey Number Player Story
3. Bundesliga Player Twin
4. Your Club DNA
5. Stadium Atmosphere Moment
6. One Last Dance

## Reusability

The generator is designed to work for different users and clubs using the same data structure. It connects data using IDs such as clubId, personId, matchId, and videoId.

The demo includes two mock users:

- user-001: Bayern-heavy user
- user-002: Dortmund/Freiburg-focused user

## Important Note

This repository uses mock data only. Original hackathon data and raw Bundesliga datasets are not included.
